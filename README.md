# iQamata LiKhaya NPO Website 
**Project Organization:** iQamata LiKhaya Non-Profit Organisation (Inception: November 2022)  

---

## 📌 Project Overview
This repository contains the official website for **iQamata LiKhaya NPO**, dedicated to community empowerment, youth development, education, and social support in Cofimvaba, Eastern Cape.

---
